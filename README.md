**🛍️ Customer Shopping Behavior Analysis**



\-> Turning raw data into meaningful business insights 📊



**📌 Overview**



This project analyzes 3,900 customer transactions to uncover patterns in shopping behavior, spending habits, and product preferences. The objective is to generate actionable insights that support smarter business decisions. 



📊 **Dataset Highlights**



📦 **Total Records:** 3,900

📈 **Features:** 18 (Demographics, Purchase Details, Behavior)

⚠️ Missing Values handled using median imputation

🧩 **Feature Engineering:**

1. Age Groups

2\. Purchase Frequency



🗂️ **Data includes:** Gender, Category, Purchase Amount, Subscription Status, Shipping Type, etc. 



⚙️ **Tech Stack**

🐍 Python (Pandas, Data Cleaning, EDA)

🗄️ PostgreSQL (SQL Analysis)

📊 Power BI (Interactive Dashboard)



🔍 **Key Analysis Performed**



💰 Revenue analysis by gender

🏷️ High-spending customers using discounts

⭐ Top-rated products

📦 Shipping type vs spending behavior

👥 Customer segmentation (New, Returning, Loyal)

🔁 Subscription impact on revenue

📊 Revenue distribution by age group

🛍️ Top products per category 



📈 **Key Insights**



💡 Discount users can still be high spenders

👥 Loyal customers dominate the dataset

🚚 Express shipping users spend slightly more

📊 Different age groups contribute significantly to revenue



📊 **Dashboard**



An interactive **Power BI dashboard** was created to visualize:



1. Revenue by category
2. Customer segmentation
3. Subscription distribution
4. Sales trends
